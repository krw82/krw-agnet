# Research Synthesis Contract

This contract is an optional presentation handoff and is independent of the SearchPlan/ResearchState retrieval contract.

It is not the default web-chat runtime. Default web chat returns Korean Markdown only.

Use this contract only when the runtime explicitly requests structured handoff for display planning, export, audit, or frontend renderer testing.

See `structured-handoff-contract.md` for the active boundary.

# KRW research final-writing references

These files are private components of the Korean research agent's immutable
prompt. They describe how already-admitted filing evidence becomes a useful
Korean answer. They are not a separate display-planning plugin and are never
shown, named, or quoted to a user.

- `research-synthesis.md`: evidence-to-investor reasoning procedure.
- `plain-korean-investor-language.md`: final Korean language and table rules.
- `final-markdown-contract.md`: direct Markdown completion boundary and
  normal/recovery examples.

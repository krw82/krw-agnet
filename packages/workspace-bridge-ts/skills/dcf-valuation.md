# DCF 밸류에이션 렌즈

티커 중심의 할인현금흐름(DCF) 관점 심층 조사를 수행한다. 이 스킬은 조사·계산의
방향을 지정할 뿐, 투자 권고가 아니다.

## 조사 순서

1. **재무 기초**: 이미 스코프에 들어온 티커의 최근 연간 재무제표(손익·재무·현금흐름)
   와 핵심 지표를 openbb 관측 평면에서 읽는다. 매출·영업이익·FCF의 3~5년 추이와
   전환점(성장 가속/둔화, 마진 변동)을 먼저 확정한다.
2. **공시 교차 확인**: FCF와 부채 구조에 구조적 변화(대규모 M&A, 리스 재분류,
   일회성 항목)가 의심되면 공시(필링)에서 원인을 확인한다. 온톨로지 커버 밖
   종목은 FMP 필링 목록으로 확인한다.
3. **결정론 계산**: 산술은 반드시 도구가 하게 한다 — `quant.dcf`(결정론 DCF
   빌트인)에 라벨이 붙은 입력(FCF 기저, WACC, 영구성장률, 순부채, 주식수)을
   제안하고, 계산 결과(주당 적정가, 구성요소, 민감도)를 그대로 인용한다.
   프롬프트에서 손계산을 하지 않는다. 기관 관점 대조: FMP 자체 DCF
   (`fmpextra dcf`, 오버라이드 없이 `fmpextra dcf_custom` — FMP가 성장률·WACC·
   터미널 성장 전부 알아서 계산)를 나란히 인용해 우리 계산과 방향을 비교한다.
4. **민감도 해석**: 기저 시나리오가 전부가 아니다 — WACC±1%p, 성장률±0.5%p에서
   결론이 뒤집히는지 밝히고, 시장가격과의 프리미엄/할인을 수치로 제시한다.
5. **정직한 한계**: 터미널값이 기업가치에서 차지하는 비중, 입력 중 추정에
   의존하는 항목(주식수, 순부채의 기준시점), 그리고 "이 계산은 모델 출력이지
   목표가가 아님"을 명시한다.

## 출력 형태

- 표 1: 투입 입력(FCF 기저·WACC·성장률·순부채·주식수, 출처 라벨 포함)
- 표 2: 기저 결과(주당 적정가·EV·지분가치·터미널 비중) + FMP 기관 DCF 대조값(있으면)
- 민감도 요약(축별 방향과 결론 민감도)
- 결론: 현재가 대비 위치, 시나리오별 함의, 후속질문 3개

워크스페이스의 "KRW DCF 민감도 히트맵"·"KRW DCF 기저 요약" 위젯과 동일한
입력 정의(시총÷시가 주식수, openbb fmp FCF)를 쓰도록 노력한다 — 위젯 숫자와
보고서 숫자가 일치해야 사용자가 서로를 검증할 수 있다.
